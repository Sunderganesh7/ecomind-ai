# EcoMind AI Knowledge Base

This directory manages the storage and indexing of scientific literature, environmental datasets metadata, and supporting documentation used for RAG (Retrieval-Augmented Generation).

## Structure
- `documents/`: Raw PDFs, research papers, and environmental reports.
- `processed/`: Cleaned and chunked text ready for vectorization.
- `metadata/`: JSON files containing metadata, citations, and source information for traceability.

**Note:** Do not populate this directory with fabricated scientific papers or fake data.
